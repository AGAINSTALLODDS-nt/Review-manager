Google Gemini API

Slow Mode (Лимиты API)
15 запросов/мин, 500/день — бесплатный лимит для моделей типа Gemini 3.5 Flash Lite. Для других моделей лимиты могут отличаться. Применяется к активному провайдеру AI. Отправка только вручную кнопкой «Отправить».
Использовано запросов сегодня: 0 / 500

Sber GigaChat API

GigaChat почти наверняка не отдаёт CORS-заголовки для запросов из браузера — как правило, нужен тот же тип прокси, что и для Ozon. Используется и для получения токена, и для генерации.

Промпты и лимит токенов — общие для Gemini и GigaChat, см. поля ниже в карточке Gemini.

Остаток токенов (Freemium, /v1/balance)
Не проверялось в этой сессии. Лимиты Freemium делятся по тиру модели (Lite/Pro/Max/Ultra) и обновляются раз в 12 месяцев — RPM-лимитов у GigaChat нет, только общий бюджет токенов.

Промпты для AI (общие для Gemini и GigaChat)
