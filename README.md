# Review manager

Веб-приложение для автоматизации работы с отзывами покупателей. Инструмент позволяет загружать отзывы, фильтровать их и генерировать профессиональные, SEO-оптимизированные ответы с помощью искусственного интеллекта (Google Gemini).

⚠️ **ВАЖНО: API Ключи и Аккаунты**
Приложение не предоставляет API-ключи. Для полноценной работы вы должны самостоятельно получить и заполнить все необходимые ключи в разделе «Настройки».

**1. Seller API**
Вам потребуются Client-ID и API-Key из вашего личного кабинета продавца.

    Зайдите в личный кабинет Seller.
    Перейдите в раздел API Keys (или настройки интеграции).
    Создайте новый ключ и скопируйте Client-ID и API-Key в настройки приложения.

**2. Google Gemini API (ИИ для генерации ответов)**
Вам необходимо самостоятельно создать аккаунт и получить ключ для доступа к моделям Google Gemini.

    Перейдите на Google AI Studio
     или в Google Cloud Console
    .
    Авторизуйтесь под своим Google-аккаунтом.
    Создайте новый API Key.
    Скопируйте ключ и вставьте его в поле API Key в настройках приложения.

   **Примечание о лимитах:** Мой бесплатный тариф Gemini имеет ограничения (обычно 15 запросов/мин и 500 запросов/день).
   Чтобы избежать ошибок rate-limit по дефолту стоит переключатель Slow Mode в настройках приложения.

**4. CORS Proxy**
Так как приложение работает напрямую в браузере, для обхода ограничений CORS при запросах к API вам может понадобиться указать URL CORS-прокси в настройках. Вы можете использовать публичные прокси или развернуть свой собственный (например, через Cloudflare Workers).

**🚀 Быстрый старт**
Приложение не требует сложной установки. 

    Скачайте файл index.html (или клонируйте репозиторий).
    Откройте файл в любом современном браузере (Chrome, Firefox, Edge) ИЛИ разместите его на любом статическом хостинге (GitHub Pages, Netlify, Vercel).
    Перейдите в раздел Настройки и заполните все API-ключи (см. раздел выше).
    Нажмите Сохранить все настройки.

**🛠 Как пользоваться**
1. Загрузка и фильтрация отзывов

    На главной вкладке нажмите «Загрузить отзывы».
    Используйте панель фильтров сверху, чтобы найти нужные отзывы:
        Статус: Новые, Просмотренные, Обработанные.
        Медиа: С фото/видео или без.
        Оценка: От 1 до 5 звезд.
        Текст: Наличие или отсутствие текста.
        Сортировка: По дате (новые/старые).

2. Генерация ответов с AI

    Выберите отзывы в таблице (или оставьте выбор по умолчанию).
    Нажмите кнопку AI или перейдите к блоку Генерация ответов с AI.
    Нажмите Начать генерацию. ИИ проанализирует текст отзыва, оценку и сгенерирует вежливый ответ.
    Совет: Вы можете отредактировать сгенерированный ответ прямо в таблице перед отправкой.

3. Шаблоны ответов

    Если вам нужно отвечать однотипно, используйте раздел Шаблоны.
    Нажмите Создать новый шаблон или Сохранить текущий ответ как шаблон.
    Шаблоны позволяют мгновенно вставлять заготовленные тексты.

4. Отправка и Экспорт

    После проверки ответов нажмите кнопку Отправить, чтобы опубликовать их на площадке.
    Для резервного копирования или анализа используйте кнопки Экспорт (JSON, Excel, CSV). Данные можно также Импортировать обратно.

**⚙️ Тонкая настройка ИИ (Промпт и Лимиты)**
В разделе Google Gemini API вы можете гибко настроить поведение ИИ:

    Промпт: По умолчанию задан оптимальный промпт. ИИ учитывает рейтинг (благодарит за 4-5, нейтрален за 3, извиняется за 1-2), пишет на русском языке, не использует символ — и обязательно упоминает конкретный товар для улучшения SEO карточки. Вы можете изменить этот текст под свои нужды.
    Лимит токенов: Рекомендуется ставить 150–200 для получения лаконичных ответов (2-3 предложения).
    Модель: Выберите нужную модель Gemini из списка (кнопка "Сначала обновите список...").

**📊 Лог действий**
Все действия, запросы к API, ответы и ошибки записываются в Лог действий внизу экрана. Это поможет вам отследить, если какой-то отзыв не удалось отправить, или понять, сколько запросов к Gemini было потрачено.

**📝 Лицензия и Отказ от ответственности**

    Храните свои API-ключи в безопасности. Не коммитьте файл с настройками, если в нем захардкожены реальные ключи (настройки сохраняются в localStorage браузера).
    Следите за расходом токенов и лимитами ваших API, чтобы избежать неожиданных списаний или блокировок.
    Всегда проверяйте сгенерированные ИИ ответы перед массовой отправкой.
