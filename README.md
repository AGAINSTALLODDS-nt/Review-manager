# Review Manager - TEST SERVER VERSION

Веб-приложение для автоматизации работы с отзывами и вопросами покупателей на Ozon. Позволяет загружать отзывы и вопросы, фильтровать их, генерировать ответы с помощью ИИ (Google Gemini) и отправлять их обратно в Ozon — без установки чего-либо, прямо в браузере.

**[Открыть сервис →](https://againstallodds-nt.github.io/Review-manager/)**

---

## ⚡ Чем это лучше нативного Ozon Seller

| | Ozon Seller (нативно) | Review Manager |
|---|---|---|
| Скачать отзывы и вопросы себе (архив, отчёты, аналитика) | ❌ Такой функции нет | ✅ Экспорт в Excel, CSV или JSON в один клик |
| Скачать видео из отзыва | ❌ Ozon не даёт скачать видео покупателя вообще | ✅ Кнопка «Скачать» — можно сохранить и фото, и видео, например для использования как UGC-контент |
| ИИ-генерация ответов | Платно — пакет ИИ-инструментов от Ozon стоит около 200 000 ₽/мес | ✅ Бесплатно, на вашем собственном ключе Google Gemini (в рамках бесплатного лимита) |
| Шаблоны ответов | Максимум 9 (30 — только на подписке Premium Plus) | ✅ Без ограничений по количеству |
| Настройка того, как именно отвечает ИИ | ❌ Стиль и содержание ответа не редактируются | ✅ Свой промпт: тон, длина, что обязательно упомянуть, чего избегать |

Всё остальное работает поверх официального Ozon Seller API — с ключом, который вы вводите сами, тем же самым, которым обычно пользуется ваша интеграция.

## 🚀 Быстрый старт

Приложение не требует регистрации, установки или особых прав — просто откройте ссылку в браузере.

1. Зайдите по ссылке **[againstallodds-nt.github.io/Review-manager](https://againstallodds-nt.github.io/Review-manager/)**.
2. Откройте **⚙️ Настройки** и введите ключи Ozon Seller API и Google Gemini API — подробно о том, где их взять, смотрите в разделе [«Настройки»](#️-настройки) ниже.
3. Нажмите кнопку рядом со списком моделей Gemini, чтобы подтянуть доступные вам модели, и выберите одну из них.
4. Готово — дальше можно работать с отзывами и вопросами. Что именно умеет сервис — разберём по порядку ниже.

### Загрузка и фильтрация

На вкладке **«Отзывы»** нажмите **«Загрузить отзывы»** — приложение подгрузит отзывы с Ozon (по умолчанию до 500 штук, за один заход; лимит страниц настраивается в Настройках, до 2000). Сразу после этого начнётся подгрузка информации о товарах (артикул, название, фото, описание) — она кешируется в браузере, повторно с Ozon не запрашивается. Кнопка **«Загрузить ещё»** подгружает следующую порцию, если отзывов больше, чем влезло за раз.

Панель фильтров сверху помогает найти нужные отзывы:
- **Статус** — новые, просмотренные, обработанные, необработанные.
- **Ozon ID / артикул** — поиск по конкретному товару.
- **Оценка** — от 1 до 5 звёзд.
- **Текст** — есть текст или без текста.
- **Медиа** — с фото/видео или без.
- **Дата** — сортировка по свежести.

Вкладка **«Вопросы»** работает так же, независимо от вкладки «Отзывы» — загружать их можно в любом порядке.

### Медиа из отзывов

Если в отзыве есть фото или видео от покупателя, они отображаются в столбце **«Медиа»**. Клик по фото открывает его крупно, клик по видео — запускает проигрывание. Кнопка **«Скачать»** сохраняет файл на компьютер.

### Ответ вручную

Можно отправлять ответы по 1 если хочется. Начните печатать прямо в поле ответа нужной строки — кнопка отправки появится сама, как только в поле есть текст.

### Генерация ответов с AI

Ответы можно генерировать массово (рекомендуется) или по одному.

**Массово:**
1. Отметьте нужные строки галочками (или воспользуйтесь меню выделения в шапке таблицы — «выбрать все», «с ответами», «без ответов»).
2. Нажмите кнопку **AI**.
3. Генерация идёт в фоне — статус и прогресс видны в строке под шапкой, при этом можно продолжать работать: писать другие ответы, отправлять уже готовые. Генерацию можно отменить в любой момент.

ИИ анализирует текст отзыва, оценку, название и описание товара и пишет ответ на основе вашего промпта (см. настройки Gemini).

> ⚠️ **Важно:** всегда проверяйте и при необходимости редактируйте сгенерированный ответ прямо в таблице перед отправкой.

### Шаблоны ответов

Раздел **«Шаблоны»** — для однотипных ответов, без ограничения по количеству. Хранятся локально в браузере.

- **«Создать новый шаблон»** — вручную.
- **«Сохранить текущий ответ как шаблон»** — превращает уже написанный ответ в шаблон на будущее.
- **Скачать/импортировать шаблоны (XLSX)** — перенос шаблонов между компьютерами; при импорте шаблон с существующим названием обновится, а не задвоится.

### Экспорт и импорт

Кнопка **«Экспорт»** — выгружает то, что сейчас видно в таблице (с учётом фильтров), в Excel, CSV или JSON. Обработав файл вне сервиса, загрузите его обратно через **«Импорт»** — не забудьте выбрать тот же формат.

### Отправка

Массово — кнопка **«Отправить»** в шапке (с возможностью отмены по ходу отправки), либо по одной строке — кнопка отправки рядом с конкретным полем ответа.

### Лог действий

Вкладка **«Настройки»** содержит **«Лог действий»** — туда пишутся все запросы к API, ответы и ошибки. Полезно, если какой-то отзыв не удалось отправить, или чтобы понять, сколько запросов к Gemini было потрачено.

## ⚙️ Настройки

### Ozon Seller API

Понадобятся **Client-ID** и **API-Key** из личного кабинета продавца.

1. Зайдите в личный кабинет Seller.
2. Перейдите в раздел настройки интеграции.
3. Найдите **Client-ID** (Seller-ID).
4. Создайте API-ключ с правами: `Question`, `Review`, `Product read-only` — либо сразу `Admin`.
5. Скопируйте Client-ID и API-ключ в соответствующие поля в «Настройках» приложения.

### Google Gemini API (ИИ для генерации ответов)

1. Перейдите в [Google AI Studio](https://aistudio.google.com/apikey) или Google Cloud Console.
2. Авторизуйтесь под своим Google-аккаунтом.
3. Создайте новый проект и ключ API.
4. Скопируйте ключ в поле **API Key** в настройках приложения.
5. Нажмите кнопку обновления списка моделей и выберите модель, доступную в рамках вашего аккаунта.

**Тонкая настройка:**
> ⚠️ **Важно:** Работоспособность тестировалась на Gemini 3.1 Flash Lite. Все базовые лимиты и промпты заточены под нее. Для использования других моделей изучите их лимиты и расходы по токенам отдельно в Google AI Studio.
- **Промпт** — по умолчанию задан оптимальный: ИИ учитывает рейтинг (благодарит за 4–5 звёзд, нейтрален за 3, извиняется за 1–2), пишет на русском, не использует символ «—» и обязательно упоминает конкретный товар для улучшения SEO карточки. Текст можно менять под свои задачи — отдельно для отзывов и для вопросов.
- **Лимит токенов** — рекомендуется 150–200 для лаконичных ответов (2–3 предложения).
- **Slow Mode** — включён по умолчанию, ограничивает частоту запросов к Gemini, чтобы не упереться в лимиты бесплатного тарифа (обычно 15 запросов/мин и 500/день). Не отключайте без необходимости.

## 🔧 Прочая техническая информация

- **Зачем нужен CORS-прокси.** Ozon API не всегда разрешает обращаться к себе напрямую из браузера — это ограничение безопасности на стороне Ozon, а не баг приложения. Если после нажатия «Загрузить отзывы» видите сетевую ошибку, укажите в поле «CORS Proxy» настроек Ozon значение `https://corsproxy.io/?` — это бесплатный публичный сервис-посредник. Работает для большинства пользователей «из коробки».
- **Gemini и доступ из России.** Сервисы Google (в том числе Google AI Studio и Gemini API) ограничивают доступ для российских IP-адресов — для регистрации, получения ключа и, возможно, самих запросов к API может понадобиться VPN. Это ограничение самого Google, приложение на это повлиять не может.
- **Где хранятся ваши данные.** Все ключи API и настройки хранятся только в вашем браузере (`localStorage`) — никуда, кроме самих Ozon и Google, не передаются. Если открыть сервис с другого устройства или в режиме инкогнито, настройки нужно будет ввести заново.
- **Лимиты Gemini** — бесплатный тариф ограничен количеством запросов в минуту и в сутки (см. «Slow Mode» выше). При достижении дневного лимита приложение предупредит и предложит подождать до завтра.
